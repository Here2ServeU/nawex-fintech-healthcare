# Database

This domain describes the data layer used by the capstone.

It covers how the course thinks about relational storage for multiple product surfaces, including reliability, FinTech, and Healthcare examples.

## What This Domain Covers

- schema planning for application data
- separation of operational and domain-specific records
- sample-data strategy for demos and teaching exercises
- the role of migrations and seed data in a delivery workflow
