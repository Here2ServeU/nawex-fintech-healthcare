# Frontend

This domain represents the user-facing layer of the capstone.

It is where students learn how product presentation, dashboards, and operational context come together for reliability, FinTech, and Healthcare use cases.

## What This Domain Covers

- dashboard design for technical products
- presenting model outputs and operational signals
- translating backend data into user-facing views
- structuring interfaces for demos and portfolio walkthroughs
