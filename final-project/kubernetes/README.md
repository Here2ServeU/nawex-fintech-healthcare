# Kubernetes

This domain documents workload deployment concepts for the capstone.

It shows how the platform is framed once students move from local development into cluster-oriented thinking.

## Public Folder Layout

- [deployments](./deployments/README.md)
- [services](./services/README.md)

## What This Domain Covers

- workload packaging and runtime boundaries
- service exposure and internal communication
- separating application concerns inside a cluster
- deployment concepts used in portfolio and interview discussions
