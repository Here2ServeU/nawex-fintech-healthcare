# NERP Course Container

This directory organizes the program into separate weekly repos plus one final flagship project.

## Recommended Root Structure For The Repository

- `weeks/`
  One teaching repo per week
- `SYLLABUS.md`
  Week-by-week teaching map

## How To Use This

Teach from only one week directory at a time.

Do not open the whole parent repository with mentees unless you are working on the final capstone.

Each week folder contains only the code surface needed for that week.
