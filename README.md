# AI Engineering Course Repository

This repository is organized into two clear entry points:

- [course](course/README.md)
  The teaching container with weekly repo-sized directories and syllabus materials
- [final-project](final-project/README.md)
  The flagship integrated project used for capstone, portfolio, and employer-facing demos

## Mentor Background

By way of background, I currently operate in DevOps and cloud engineering, and I am also a PhD researcher focused on AI, machine learning, and robotics applied to highly regulated environments. In addition, I have worked with clients for over 10 years on technology and transformation initiatives. This mentorship combines that perspective with practical, real-world execution.

## How To Use This Repository

### If you are teaching

Start in:

- [course/README.md](course/README.md)
- [course/SYLLABUS.md](course/SYLLABUS.md)

Teach from one weekly directory at a time under:

- [course/weeks](course/weeks)

### If you are showing the finished product

Start in:

- [final-project/README.md](final-project/README.md)

Use that directory for:

- capstone demos
- portfolio packaging
- interview walkthroughs
- consulting or client demonstrations
